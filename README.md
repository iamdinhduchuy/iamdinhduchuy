## 🚀 What I Build

### 🎮 HyperOU

**HyperOU** is a real-time esports platform built specifically for Free Fire tournament production and broadcast workflows.

It connects tournament data, live game events, broadcast graphics, and production tools into a unified real-time system.

**Core systems:**

- 📊 Real-time tournament scoreboard & statistics
- 🎮 Live game-state and match event synchronization
- 🎥 Broadcast graphics & production systems
- 🔌 WebSocket-based real-time communication
- 🏆 Tournament management
- 📺 OBS / vMix integration
- 🌐 Web-based tournament infrastructure
